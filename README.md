# Сканер электросхем

Полуавтомат «картинка схемы → netlist» для работы вместе с Claude (Claude Code).
Подходит для схем из книг, сканов и картинок из интернета.

Программа готовит картинку так, чтобы ИИ читал её без ошибок, а потом помогает
человеку проверить результат.

## Как это работает

1. **Подготовка.** Программа выпрямляет наклон, убирает цветной фон и тени,
   накладывает сетку (A1, B2, …) и режет схему на увеличенные фрагменты
   с перекрытием в одну клетку.
2. **Распознавание.** Кнопка «Задание для Claude» копирует текст. Его нужно вставить
   в Claude Code. Claude читает фрагменты и пишет `netlist.json` в папку проекта.
3. **Проверка.** Программа сама подхватывает `netlist.json` и показывает:
   - компоненты и цепи — щелчок подсвечивает их на картинке;
   - ошибки: оборванные цепи, повторы обозначений, пустые номиналы;
   - функциональные блоки с описанием работы;
   - вопросы Claude по спорным местам.
4. **Поправки.** Правый клик по клетке — оставить вопрос или поправку для Claude
   (`notes.json`). В следующий раз Claude их учтёт.
5. **Экспорт.** SPICE-netlist (`schematic.cir`), список элементов (`bom.csv`)
   и текстовое описание (`summary.md`).

## Установка и запуск

Нужен Python 3.10+ (Windows).

```bash
pip install -r requirements.txt
python app.py
```

На Windows можно просто запустить `Запуск.bat`.

## Без интерфейса

```bash
python core.py prep схема.jpg            # подготовить проект
python core.py check схема_project       # проверить netlist.json
python core.py export схема_project      # SPICE, BOM, описание
python core.py zoom схема_project F5:G6  # крупно спорное место
```

## Папка проекта

| Файл | Что это |
|---|---|
| `original.*`, `source.png` | исходная картинка и выпрямленная |
| `clean.png` | очищенная (без фона и теней) |
| `overview.png` | весь лист с сеткой |
| `tiles/` | увеличенные фрагменты для Claude |
| `manifest.json` | сетка и список фрагментов |
| `CLAUDE_TASK.md` | задание и формат netlist для Claude |
| `netlist.json` | результат распознавания (пишет Claude) |
| `notes.json` | вопросы и поправки пользователя |
| `export/` | SPICE, BOM, описание |
