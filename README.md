# Сканер электросхем

Программа превращает картинку схемы (скан из книги, фото, картинку из интернета) в netlist,
проверяет её расчётами по законам электротехники и подсказывает вероятные причины отказа.
Работает вместе с Claude (Claude Code), но умеет и многое без ИИ, и сама дообучается.

## Что внутри

| Модуль | Что делает |
|---|---|
| `core.py` | подготовка картинки: **фото листа под углом выравнивается по перспективе**, негатив обращается, выпрямление наклона, очистка фона, сетка A1…, фрагменты для Claude; проверка и экспорт netlist |
| `analyzer.py` | **анализ без ИИ**: провода, точки соединений, корпуса, символы, надписи → цепи N1, N2…; классификатор символов |
| `synth.py` | генератор учебных схем с известным ответом, **5 уровней сложности** (от пары деталей на чистом листе до плотной схемы, снятой телефоном: стол, перспектива, тени, расфокус); **схемы управления** — шины L/N, ступени «контакты → катушка», кнопки с самоподхватом, тепловые реле, автоматы, лампы, двигатели; силовые узлы, ОУ, КИП (датчики PT/TT/FT/LT, Pt100/NTC, термопары), МК, кварцы, светодиоды, клеммники, энкодеры, тахогенераторы, датчики Холла; порча «как скан/фото» |
| `learn.py` | **самообучение** (в том числе по ступеням: `learn.py curriculum`): подбор порогов анализатора, классификатор символов, проверенные проекты как реальные примеры, защита от переобучения |
| `physics.py` | **расчёты с формулами**: режим по постоянному току (узловые потенциалы), АЧХ до 1 МГц с паразитными ESR/ESL, мощности, нагрев, предзаряд, выпрямители, стабилизаторы, затворы и бутстреп, ОУ, токовая петля 4–20 мА, Pt100/NTC/термопары, МК (АЦП, выводы, кварц, I²C, сброс), энкодеры, тахогенераторы, обратная связь по напряжению |
| `diagnose.py` | **диагностика**: роли деталей, виды отказов, симптомы, слабые места схемы, физическая нагрузка; учится на подтверждённых ремонтах |
| `symlib.py` | **эталонные УГО** по ГОСТ ЕСКД (2.728, 2.730, 2.755, 2.756, 2.743, 2.759) и IEC/ANSI: резисторы, конденсаторы, диоды, тиристоры, симисторы, транзисторы, оптопары, контакты реле и пускателей, реле времени, тепловые реле, кнопки, катушки, предохранители, автоматы, ОУ, логика, триггер Шмитта — каждый разбирается анализатором и учит классификатор (`python symlib.py`) |
| `symclass.py` | **второе мнение о типе символа**: перцептрон (numpy) на признаках формы — направления штрихов (HOG), замкнутые контуры, силуэт, выводы у краёв; если он не согласен с основным классификатором, деталь в netlist без ИИ помечается неуверенной и уходит в вопросы (`python symclass.py train`) |
| `analog.py` | **аналоговые и логические узлы**: повторитель, неинвертирующий усилитель, триггер Шмитта на ОУ/компараторе (пороги и гистерезис по формулам), компаратор без гистерезиса, пороги и RC-генератор логических триггеров Шмитта, дешифраторы и шифраторы (разрешающие входы, какой код включает какой выход) |
| `checkplan.py` | **план проверки**: где вероятная причина (детали и клетки схемы) и по шагам — безопасность и разряд конденсаторов (τ = R·C), осмотр, измерения без питания с нормами (R ±5 %, C и ESR, L, прозвонка диодов, транзисторов, MOSFET/IGBT, предохранителей, контактов, катушек, обмоток, датчиков), напряжения под питанием по расчёту, пошаговое прохождение цепи управления до катушки, защиты |
| `faults.py` | **моделирование поломок**: обрыв, КЗ, уход номинала, пробой ключа, обрыв датчика для каждой детали → какие симптомы даёт; поиск поломки по измеренным напряжениям и подсказка, где мерить дальше |
| `parts.py`, `parts_db.json` | **справочник деталей** (≈290, у каждой новой записи `src` — откуда значение; часть сверена со скачанными даташитами TI и Vishay; добавлены триггеры Шмитта, дешифраторы/шифраторы, компараторы, реле, контакторы, тепловые реле: MOSFET, IGBT, транзисторы, диоды, TVS, мосты, стабилизаторы, ШИМ, драйверы, оптроны, ОУ, тиристоры, МК, датчики, интерфейсы) + импорт параметров из PDF-даташита |
| `app.py` | окно программы |

## Как пользоваться

1. **«Открыть картинку…»** — картинка готовится, и сразу запускается анализ без ИИ.
   Кнопка «Оригинал / чистая / цепи» показывает найденные цепи разными цветами.
2. **«Задание для Claude»** — скопировать задание, вставить в Claude Code. Claude пишет `netlist.json`,
   используя разбор без ИИ как подсказку. Программа подхватывает файл сама.
3. Проверить результат на вкладках, правым кликом по клетке оставить Claude вопрос или поправку.
4. **Вкладка «Диагностика»**: отметить симптомы или написать словами («двигатель не запускается, пускатель гудит») → «Найти причины».
   Сверху — **план проверки**: где вероятная причина и что по порядку померить, с ожидаемыми значениями;
   клик по шагу подсвечивает детали на схеме. Сверху — слабые места схемы
   (с формулами и числами), ниже — детали по вероятности, у каждой: почему и как проверить.
   После ремонта — «Деталь неисправна» / «Деталь исправна»: модель это запоминает.
   **Измерения**: введите напряжения, которые намерили мультиметром (`ADC0N=0; AI1=0,02`), —
   программа найдёт поломку, которая их объясняет, и скажет, где мерить дальше, чтобы различить кандидатов.
   **Справочник**: найти деталь или импортировать её параметры из PDF-даташита (проверяйте результат).
5. **Условия (physics.json)**: ток нагрузки, частота ШИМ, температура, радиатор, питание петли,
   обороты двигателя, длина кабеля и т.п. — без них часть расчётов пропускается.

## Самообучение

- Каждая схема, у которой `netlist.json` прошёл проверку без ошибок, автоматически становится
  учебным примером (`learn.py add`): символы с типами — в классификатор, связи — в оценку анализатора.
- **«Дообучить»** (или `python learn.py auto`) — переучить классификатор и подобрать пороги на синтетике
  и на всех проверенных схемах. Параметры, при которых на реальных схемах теряются точки соединения,
  отвергаются (защита от переобучения на синтетике).
- Диагностика учится на подтверждённых ремонтах (`learned/repairs.jsonl`) и на моделировании:
  каждая открытая схема прогоняется через все типичные поломки, и статистика «тип и роль детали → симптом»
  копится по всем схемам (`learned/sim_stats.json`) — поэтому новые схемы диагностируются точнее.

Всё выученное лежит в папке `learned/`.

## Без окна

```bash
python core.py prep схема.jpg            # подготовить проект
python analyzer.py схема_project         # анализ без ИИ
python physics.py схема_project          # расчёты с формулами
python diagnose.py схема_project overspeed,noisy   # причины отказа по симптомам + план проверки
python diagnose.py схема_project "не запускается двигатель"   # то же, симптомы словами
python diagnose.py symptoms              # список симптомов
python diagnose.py confirm схема_project R11 overspeed   # деталь оказалась неисправна
python faults.py схема_project                  # какие поломки какие симптомы дают
python faults.py схема_project ADC0N=0 AI1=0.02 # поиск поломки по измерениям
python parts.py find IRFP460 | list MOSFET | import даташит.pdf
python learn.py eval | tune | symbols | add проект | auto
```

## Установка

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python app.py
```

На Windows — `Запуск.bat`. Для распознавания текста надписей можно поставить Tesseract (rus+eng) и
`pip install pytesseract` — анализатор подхватит его сам.

## Ограничения

Справочные данные деталей — типовые значения из даташитов, сверяйте с даташитом своей детали.
Вероятности диагностики — относительные оценки по правилам и истории ремонтов, а не замена измерениям.
Анализ без ИИ надёжен на чистых чертежах и заметно хуже на старых сканах и фото — там главный распознаватель Claude.
Если на картинке много полутонов (фото платы или прибора, а не схема), анализатор об этом предупреждает.
